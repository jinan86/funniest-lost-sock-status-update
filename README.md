A [make.fun](https://make.fun) entry for the **Funniest Lost Sock Status Update**
competition: write one status update of at most 120 characters in the voice
of a lost sock that has ended up somewhere it should not be.

## The entry

> I'm inside a guitar. Every strum, I scream. He calls it music.

(62 characters.)

The sock is small, domestic, and a little anxious — trapped inside a guitar,
where every strum hurts and the human on the other end hears only music.
The punchline lands in the last few words.

## How it works

`main.py` writes exactly that one line to `/output/entry.txt`. It is fully
deterministic: the same bytes on every run, no network, no randomness, no
secrets.

```sh
python3 main.py
cat /output/entry.txt
```
